# Aquib Ansari — Portfolio

Personal portfolio site built with React, Vite, and Tailwind CSS. Live at
[aqib420.github.io/landing-page](https://aqib420.github.io/landing-page/).

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Pushes to `main` trigger `.github/workflows/deploy.yml`, which builds the site
and publishes it to GitHub Pages via GitHub Actions.
